# Czuze — космический паёк

Учебный магазин на HTML, CSS и JavaScript. В каталоге три товара с ценами в рублях. Товары можно добавлять и удалять, общая сумма пересчитывается сразу. Повторное добавление создаёт отдельную строку. После перезагрузки корзина очищается.

## Запуск

Откройте `site/index.html` в браузере. Для запуска через локальный сервер из корня репозитория используйте Python 3.12+ без сторонних зависимостей.

```sh
python3 main.py
```

Адрес магазина — [localhost:8000](http://localhost:8000). В Windows вместо `python3` можно использовать `py -3`.

## ZIP для сдачи

```sh
python3 main.py --pack
```

Команда создаёт `shop.zip` в корне проекта. Распакуйте архив и откройте `index.html` в браузере.

## Сценарий проверки

1. Откройте каталог. Проверьте три товара и итог 0 ₽.
2. Добавьте лунный батончик за 100 ₽ и марсианский суп за 200 ₽. В корзине две строки, итог 300 ₽.
3. Удалите батончик. В корзине остался суп, итог 200 ₽.
4. Удалите суп. Корзина пуста, итог 0 ₽.
5. Дважды добавьте орбитальный чай. В корзине две строки, итог 100 ₽. Удалите одну строку и проверьте итог 50 ₽.

Проверка сервера и упаковки — `python3 tests/smoke.py` и `python3 tests/test_pack.py`.
