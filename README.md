# Czuze — Лавка отладчика

Учебный магазин на HTML, CSS и JavaScript. В каталоге три товара с ценами в рублях. Товары можно добавлять и удалять, общая сумма пересчитывается сразу. Последнее действие видно в журнале корзины. Повторное добавление создаёт отдельную строку. После перезагрузки корзина очищается.

## Запуск

Откройте `site/index.html` в браузере. Для запуска через локальный сервер из корня репозитория используйте Python 3.12+ без сторонних зависимостей.

```sh
python3 main.py
```

Адрес магазина — [localhost:8000](http://localhost:8000). В Windows вместо `python3` можно использовать `py -3`.

## ZIP для сдачи

```sh
python3 main.py --pack
```

Команда создаёт `shop.zip` в корне проекта. Распакуйте архив и откройте `index.html` в браузере.

## Сценарий проверки

1. Откройте каталог. Проверьте три товара и итог 0 ₽.
2. Добавьте резиновую утку за 100 ₽ и запасную Esc за 200 ₽. В корзине две строки, итог 300 ₽.
3. Удалите утку. В корзине осталась Esc, итог 200 ₽.
4. Удалите Esc. Корзина пуста, итог 0 ₽.
5. Дважды добавьте кофе. В корзине две строки, итог 300 ₽. Удалите одну строку и проверьте итог 150 ₽ и сообщение в журнале.

Проверка сервера и упаковки — `python3 tests/smoke.py` и `python3 tests/test_pack.py`.
