# Czuze — Лавка отладчика

Учебный магазин с девятью товарами для рабочего стола разработчика. Одинаковые товары группируются в корзине, количество меняется кнопками «−» и «+». Избранное, корзина, оформление и заказы открываются отдельными страницами через верхнее меню. Корзина, избранное, промокод и история заказов сохраняются в этом браузере под ключом `czuze:shop:v1`. В карточке каждого товара есть два сгенерированных ракурса. Промокод `DEBUG10` даёт 10% скидки. Чтобы убрать скидку, очистите поле и снова нажмите «Применить».

[Открыть магазин на GitHub Pages](https://itmo-workshop-09-11-2026.github.io/Czuze/)

## Запуск и сдача

Откройте `site/index.html` в браузере. Для работы с API запустите из корня проекта Python 3.12+ без сторонних пакетов.

```sh
python3 main.py
```

Магазин и API работают на [localhost:8000](http://localhost:8000). При первом запуске SQLite создаёт `data/shop.sqlite3` и загружает товары из `site/catalog.js`. Для чистых тестовых данных задайте `SHOP_DB` с новым путём. В Windows используйте `py -3`. Настройки передаются переменными окружения. В `.env.example` перечислены имена переменных.

```sh
python3 main.py --pack
```

Получится `shop.zip` с `index.html` в корне. Распакуйте его и откройте страницу. GitHub Pages и ZIP используют статический каталог. На GitHub Pages и в ZIP можно оформить демонстрационный заказ без оплаты. Случайный стартовый остаток сохраняется в браузере и уменьшается после заказа. При запуске Python-сервера заказы и остатки записываются в SQLite. Для новой базы стартовые остатки выбираются случайно, существующие остатки сохраняются. GitHub Actions публикует `site/` при push в `main`, также доступен ручной запуск **Publish site**.

## API

- `GET /api/products?q=утка&category=Отладка` ищет товары по названию и категории. Оба параметра необязательны. Цены каталога указаны в целых рублях.
- `POST /api/orders` принимает строки с ID и количеством, а также необязательные `promo` и `requestId`. Сервер возвращает ID и итог в копейках, рассчитывает сумму по каталогу и списывает остатки в одной транзакции. Повтор с тем же `requestId` и составом возвращает прежний заказ.
- `PUT /api/products/<id>` создаёт или обновляет товар. Перед запуском сервера задайте `SHOP_ADMIN_TOKEN` и передавайте его в заголовке `X-Admin-Token`. Поля `name`, `price`, `category`, `description`, `image` и `stock` обязательны. `image` — имя файла из `site/assets/`.

```sh
curl http://localhost:8000/api/products
curl -H 'Content-Type: application/json' \
  -d '{"items":[{"productId":"duck","quantity":3}],"promo":"DEBUG10"}' \
  http://localhost:8000/api/orders
curl -X PUT -H 'Content-Type: application/json' -H "X-Admin-Token: ${SHOP_ADMIN_TOKEN}" \
  -d '{"name":"Утка XL","price":300,"category":"Отладка","description":"Для сложных багов","image":"duck.svg","stock":2}' \
  http://localhost:8000/api/products/duck-xl
```

## Проверка

1. Добавьте четыре утки. В корзине одна строка с количеством 4 и итогом 400 ₽. Уменьшите количество до 3, примените `DEBUG10` дважды. Итог оба раза 270 ₽. Обновите страницу, затем удалите строку и проверьте итог 0 ₽.
2. Найдите утку через поиск, выберите категорию, поменяйте порядок цен, сбросьте фильтры. Добавьте товар в избранное и откройте одноимённую страницу. Нажмите на фото товара и переключите ракурс. Карточка показывает заглушку при ошибке загрузки картинки.
3. Проверьте мобильную ширину и пройдите от каталога до корзины клавишами Tab и Enter.
4. Перейдите из корзины к оформлению и подтвердите заказ. Проверьте переход в историю и очистку корзины. Повторите сценарий через локальный сервер и обновите каталог. Проверьте ID заказа и уменьшение остатка. Попробуйте оформить заказ на количество больше остатка.

Автоматические проверки запускаются через `make test` или командами ниже. Для JavaScript-проверки нужен Node.js.

```sh
node tests/shop.test.cjs
python3 tests/test_api.py
python3 tests/test_pack.py
python3 tests/smoke.py
```
